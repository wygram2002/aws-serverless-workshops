# Daily shutdown

Goal: every loose end in the system, the day logged, the user free to switch off.
Five minutes; then done means done.

## Steps

1. **Final sweep**: "Anything still on your mind — tasks, loose ends, promises?" → Inbox rows, capture rules apply. No processing now.
2. **Reconcile the Today tab**: each intention — done → Status DONE + Log row + clear from Next Actions; not done → ask once: carry or drop. Then: anything done that wasn't on the list? Log it.
3. **Hand-offs**: one question — anything handed off / newly waiting? → Waiting On rows.
4. **Log the day** (+ optional one-line day note; don't fish for feelings). Optionally one question: tomorrow's first move → note it in the Log row; /brief picks it up.
5. **One Board rebuild** with all of the above (read live Board first — preserve user cell edits, Comms included).
6. **Close definitively**: confirm everything is captured, give explicit permission to switch off. Short. No new topics.

## Rules

- No project walks, no priority overhauls, no inbox processing here.
- Something big surfacing in the sweep → capture it; it's tomorrow's problem.
- Skipped intentions are data, not sins.
